# LEXAUDIT // Asistente Jurídico

**Proyecto de Inteligencia Artificial (IA) — Chatbot de orientación jurídica**

LEXAUDIT es un prototipo de chatbot diseñado para ofrecer orientación jurídica general, principalmente sobre situaciones contractuales y legislación colombiana.

El proyecto busca explorar cómo una interfaz conversacional puede facilitar el acceso inicial a información jurídica mediante una experiencia intuitiva, organizada y accesible.

## Características principales

- **Interfaz conversacional:** interacción mediante burbujas de mensajes diferenciadas para el usuario y el asistente.
- **Estado vacío (Empty State):** pantalla inicial de bienvenida que invita a comenzar una conversación.
- **Consultas rápidas:** preguntas predefinidas sobre situaciones jurídicas frecuentes.
- **Respuestas con fuentes:** presentación de criterios jurídicos y referencias normativas.
- **Estado de carga:** simulación visual del procesamiento de consultas.
- **Manejo de errores:** identificación de consultas fuera del alcance del prototipo.
- **Atención humana:** simulación de derivación a un abogado o asesor.
- **Diseño responsive:** adaptación a diferentes tamaños de pantalla.
- **Aviso legal permanente:** comunicación de los límites del asistente.

## Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| HTML5 | Estructura y contenido de la aplicación. |
| CSS3 | Diseño, estilos, animaciones y transiciones. |

**Restricción técnica:** el proyecto está desarrollado exclusivamente con HTML y CSS, sin JavaScript.

## Diseño e interfaz

La interfaz utiliza una estética sobria y profesional, con una paleta basada en azul marino, blanco y detalles dorados.

Se priorizan los siguientes principios:

- Jerarquía visual.
- Legibilidad.
- Contraste.
- Accesibilidad.
- Consistencia visual.
- Experiencia conversacional.
- Adaptabilidad a dispositivos móviles.

## Alcance y limitaciones

LEXAUDIT es un prototipo de interfaz frontend.

Debido a que no utiliza JavaScript ni cuenta con un backend, las interacciones están predefinidas mediante HTML y CSS.

Por lo tanto:

- No procesa preguntas de texto libre.
- No consulta bases de datos jurídicas en tiempo real.
- No verifica automáticamente la vigencia de las normas.
- No genera conceptos jurídicos personalizados.
- No realiza derivaciones reales a profesionales.

Las respuestas presentadas tienen fines demostrativos y educativos.

**Aviso legal:** Asistente de orientación jurídica general; no emite conceptos legales vinculantes ni reemplaza a un abogado.

## Ejecución

No requiere instalaciones ni dependencias adicionales.

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar `index.html` en un navegador web.
4. Seleccionar las preguntas disponibles para explorar las interacciones.
